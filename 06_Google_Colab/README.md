# 🚀 Folder: 06_Google_Colab

Folder ini memuat notebook Jupyter mandiri (*standalone*) dan panduan operasional penggunaan Google Colab untuk presentasi, demo, dan evaluasi hasil analisis kelompok 23 bersama tim maupun dosen.

---

### 📋 Berkas yang Tersedia

1. [`Proyek_Penambangan_Data_Puskesmas_Teluk_Sasah.ipynb`](Proyek_Penambangan_Data_Puskesmas_Teluk_Sasah.ipynb)
   * **Deskripsi**: Notebook Jupyter lengkap yang menggabungkan seluruh alur data mining (Script 1 Preprocessing, Script 2 EDA & Korelasi Klinis, Script 3 Forecasting & Evaluasi MAPE) ke dalam 19 cell terstruktur.
   * **Fitur Utama**:
     * Auto-detect berkas zip & Excel tanpa perlu pengaturan path rumit.
     * Rendering visualisasi grafik langsung (*inline*) di dalam browser.
     * Tabel interaktif hasil peramalan dan rekomendasi pengadaan *Safety Stock*.
     * Tombol otomatis untuk mengunduh hasil olahan ke file CSV.

2. [`PANDUAN_GOOGLE_COLAB.md`](PANDUAN_GOOGLE_COLAB.md)
   * **Deskripsi**: Panduan lengkap langkah demi langkah (*step-by-step*) cara mengunggah dan mengeksekusi notebook di platform Google Colab, serta ringkasan poin-poin penting untuk bahan diskusi perbandingan (*compare*) bersama tim kelompok.
